# Lesson 02 – Variables

[English](README.md) | [Português (BR)](README.pt-BR.md) · [Back to root](../../README.md)

## Focus
Store values in variables and combine them with arithmetic operators.

## Prerequisites
[Lesson 01](../01-first-program)

## Concepts
- Assigning values with `=`
- Naming conventions (`snake_case`, meaningful names)
- Arithmetic operators: `+`, `-`, `*`, `/`
- Using the result of one expression in another variable

## Files
- [variables.py](variables.py)

## Exercises
1. Create `salary` and `expenses`, then compute `balance = salary - expenses`.
2. Print the three values.
3. Change a value and predict the new result before running.

## Expected outcome
You can model a small real-world calculation with named variables and predict its output.

## Why it matters for ML
Features, labels and hyperparameters are all just named values. Good naming keeps experiments readable.

- [ ] I can explain what a variable is
