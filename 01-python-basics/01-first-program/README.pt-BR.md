# Aula 01 – Primeiro Programa

[English](README.md) | [Português (BR)](README.pt-BR.md) · [Voltar ao início](../../README.pt-BR.md)

## Foco
Escrever e executar o primeiro programa em Python e entender os tipos básicos de dados.

## Pré-requisitos
Python instalado e um editor de código pronto.

## Conceitos
- `print()` para exibir saída
- Strings (`str`), inteiros (`int`), decimais (`float`) e booleanos (`bool`)
- `type()` para inspecionar o tipo de um valor
- Conversão de tipos (casting), ex.: `int("10")`
- Comentários com `#`

## Arquivos
- [first_program.py](first_program.py)

## Exercícios
1. Crie variáveis com um nome, uma idade e uma linguagem, e imprima cada uma.
2. Imprima o tipo de cada variável com `type()`.
3. Guarde um número como string (`"10"`), converta com `int()` e some com outro número.

## Resultado esperado
Você consegue executar um arquivo `.py`, diferenciar `str`, `int`, `float` e `bool`, e explicar por que `"10" + 5` falha enquanto `int("10") + 5` funciona.

## Por que importa para ML
Datasets misturam texto, inteiros, decimais e booleanos. Conhecer os tipos, e converter entre eles, é o primeiro passo da limpeza de dados.
