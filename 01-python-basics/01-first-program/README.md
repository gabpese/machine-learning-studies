# Lesson 01 – First Program

[English](README.md) | [Português (BR)](README.pt-BR.md) · [Back to root](../../README.md)

## Focus
Write and run the first Python program, and understand the basic data types.

## Prerequisites
Python installed and a code editor ready.

## Concepts
- `print()` to show output
- Strings (`str`), integers (`int`), floats (`float`) and booleans (`bool`)
- `type()` to inspect the type of a value
- Type conversion (casting), e.g. `int("10")`
- Comments with `#`

## Files
- [first_program.py](first_program.py)

## Exercises
1. Create variables holding a name, an age and a language, and print each one.
2. Print the type of each variable with `type()`.
3. Store a number as a string (`"10"`), convert it with `int()` and add it to another number.

## Expected outcome
You can run a `.py` file, tell `str`, `int`, `float` and `bool` apart, and explain why `"10" + 5` fails while `int("10") + 5` works.

## Why it matters for ML
Datasets mix text, integers, decimals and booleans. Knowing types, and converting between them, is the first step of cleaning data.
