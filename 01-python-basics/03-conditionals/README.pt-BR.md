# Aula 03 – Condicionais

[English](README.md) | [Português (BR)](README.pt-BR.md) · [Voltar ao início](../../README.pt-BR.md)

## Foco
Fazer o programa seguir caminhos diferentes conforme condições.

## Pré-requisitos
[Aula 02](../02-variables)

## Conceitos
- `if`, `elif`, `else`
- Operadores de comparação: `>=`, `==`, `!=`, ...
- Operadores lógicos: `and`, `or`, `not`
- Variáveis booleanas usadas diretamente como condição
- A ordem das verificações importa (a mais específica primeiro)

## Arquivos
- [conditionals.py](conditionals.py)

## Exercícios
1. Escreva uma validação de entrada: VIP, ingresso comum ou negada, com base em idade, ingresso, bloqueio e status VIP.
2. Altere as variáveis para exercitar todos os ramos.
3. Adicione uma mensagem final que sempre é impressa, independentemente do ramo.

## Resultado esperado
Você consegue construir uma decisão com várias condições e prever à mão qual ramo será executado.

## Por que importa para ML
Regras de decisão são a intuição por trás das árvores de decisão. A limpeza de dados também usa condições (ex.: descartar linhas inválidas).
