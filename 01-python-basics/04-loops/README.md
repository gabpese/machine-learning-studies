# Lesson 04 – Loops

[English](README.md) | [Português (BR)](README.pt-BR.md) · [Back to root](../../README.md)

## Focus
Repeat actions over collections of data using lists and `for` loops.

## Prerequisites
[Lesson 03](../03-conditionals)

## Concepts
- Lists and their methods: `append()`, `insert()`, `remove()`, `pop()`, `len()`
- `for item in list`
- Counters and accumulators (`+= 1`)
- Conditionals inside loops

## Files
- [loops.py](loops.py)

## Exercises
1. Create a list of grades and print "Approved" or "Failed" for each (pass mark: 7).
2. Count how many students passed with an accumulator.
3. Practice the list methods listed above on the same list.

## Expected outcome
You can process every item of a list, apply a rule to each one and produce an aggregated result.

## Why it matters for ML
Datasets are collections of rows. Iterating, filtering and counting is the manual version of what NumPy and Pandas will later do for you.
