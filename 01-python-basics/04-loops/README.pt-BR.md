## Foco
Repetir ações sobre coleções de dados usando listas e laços `for`.

## Pré-requisitos
[Aula 03](../03-conditionals)

## Conceitos
- Listas e seus métodos: `append()`, `insert()`, `remove()`, `pop()`, `len()`
- `for item in lista`
- Contadores e acumuladores (`+= 1`)
- Condicionais dentro de laços

## Arquivos
- [loops.py](loops.py)

## Exercícios
1. Crie uma lista de notas e imprima "Approved" ou "Failed" para cada uma (média: 7).
2. Conte quantos alunos foram aprovados com um acumulador.
3. Pratique os métodos de lista acima na mesma lista.

## Resultado esperado
Você consegue percorrer todos os itens de uma lista, aplicar uma regra a cada um e produzir um resultado agregado.

## Por que importa para ML
Datasets são coleções de linhas. Iterar, filtrar e contar é a versão manual do que NumPy e Pandas farão por você.
